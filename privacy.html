Privacy policy

Minecraft HQ Backup · Effective November 9, 2026

Purpose and operator

This personal-use app is operated by its Google account owner to store and restore encrypted backups using rclone. It is not offered as a service to the public.

Data accessed and used

The app requests Google Drive's per-file access permission (drive.file). It uses this permission to create and manage its dedicated backup folder and authorized files, including uploads, downloads, updates, and owner-directed deletion. It may read account storage quota information to check available space. It does not request broad access to unrelated existing Drive files.

Storage and protection

Backup file contents, filenames, and directory names are encrypted locally with rclone crypt before upload. Encrypted files are stored in the owner's Google Drive. Google can still process metadata such as sizes, timestamps, and account activity. Downloaded backups are decrypted locally for recovery.

OAuth credentials and encryption settings are held in an encrypted local rclone configuration protected by Windows account permissions. Recovery credentials are managed separately by the owner. No credentials or backup files are published on this website.

Sharing and other uses

The operator does not sell Google user data, use it for advertising, or use it to train AI models. The backup workflow transfers encrypted data to Google Drive at the owner's direction; it does not distribute backups to other recipients. Google processes data under its own terms and privacy policy.

Retention and control

The owner controls how long backups and local recovery files are retained. There is no scheduled deletion policy established by this website. The owner may delete app-created files in Google Drive and revoke the app's access through Google Account connections. Revoking access does not itself delete files already stored.

Website hosting

This informational website is hosted on GitHub Pages. These pages contain no analytics scripts, forms, embedded trackers, or external font requests. GitHub may process visitor connection information as part of hosting the site; see GitHub's privacy statement.

Contact and updates

The app's Google authorization screen provides the owner-managed support contact. This page will be updated if the app's data practices change.
