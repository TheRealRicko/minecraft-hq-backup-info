Minecraft HQ Backup

Minecraft HQ Backup is a personal-use backup configuration operated by its account owner. It uses rclone to encrypt files locally before uploading them to a dedicated folder in the owner's Google Drive, and to download and decrypt them for recovery.

This is not a public backup service. It does not offer account registration or accept other people's files.

Google Drive access

The app requests per-file Google Drive access (drive.file) to create and manage its backup folder and files. It does not request permission to browse all existing Drive files. Authorized files can be uploaded, downloaded, updated, or deleted by the owner through rclone.

Backup file contents and names are encrypted using rclone crypt before upload. Google still receives storage metadata, such as ciphertext sizes and timestamps.
